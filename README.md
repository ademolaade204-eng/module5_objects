# Device Charging Simulation System 
An object-oriented Java application that simulates and monitors real-time charging states for developers and power banks. Built as a core graduation project demonstrating clean coding practices, custom exception handling, and robust unit testing.

## 🚀 Key Features
* **Object-oriented Architecture:** Modeled real-world entities like JavaStudent and FrontendDEV implementing a shared Chargeable interface.
*  **Dynamic Logging:** Automatically tracks and appends charging events to a localized simulation_log.txt via efficient I/O streams.
*  **Custom Exception Handling:** Engineered a robust BatteryExhaustedException to catch critical System states safely.
*  **Unit Testing:** Features comprehensive edge-case validation using JUnit inside ProgrammerTest.java.

## 🛠️Tech Stack
* **Language:** Java (Core,OOP, FILE I/O)
* **Testing:** JUnit5
* **Version Control:** Git & GitHub
